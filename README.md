# AISolutions

Industrial-AI solutions portfolio by [Sowthri](https://github.com/sowthri-industrial-ai) —
applied AI projects across three tracks, plus the website that showcases them.

## Layout

| Folder | Purpose |
|--------|---------|
| [`portfoliowebsite/`](portfoliowebsite/) | Portfolio website that showcases the work in this repo. |
| [`agenticai/`](agenticai/) | **Agentic AI** track — autonomous agents, orchestration, tool use. |
| [`assetsai/`](assetsai/) | **Assets AI** track — AI for industrial assets and equipment. |
| [`physicalai/`](physicalai/) | **Physical AI** track — AI for the physical world. |
| [`docs/`](docs/) | Repository-wide documentation. |

Each track folder follows the same shape: a `README.md` describing the track,
a `projects/` folder with one subfolder per project, and a `docs/` folder for
track-level documentation.
